# M03v0.0.1 Full hierarchical model

## Data

| Symbol | Definition |
| --- | --- |
| $P$ | Set containing every stable political component needed to represent the historical observations and the scenario ballot |
| $I$ | Set of information sources (elections or polls) |
| $I^{poll}$ | Subset of $I$ containing only polls |
| $I^{election}$ | Subset of $I$ containing only elections |
| $T$ | Set containing the dates of the elections and polls in $I$, plus the future election's date. Note that the length of $I$ and $T$ may differ by more than 1 because multiple elections or polls can occur in the same date. |
| $C$ | Set of physical cells (municipalities or, where its ballots differ, the municipality–college part used for generation) |
| $C_i$ | For each $i \in I$, subset of $C$ containing the cells in which the information is collected (the cells where the election took place or the cells from where the poll's answers were collected) |
| $L_{c,i}$ | For each $i \in I$ and $c \in C_i$, the lists on the ballot of election $i$ in municipality $c$ or the answers offered to the poll responder. For a poll, this may contain a "other lists" answer. |
| $M_{c,i}$ | For each $i \in I$ and $c \in C_i$, a $\dim(L_{c,i}) \times \dim(P)$ membership matrix, which entries are zero or one. If $M_{l,j,c,i} = 1$ then component $j$ is represented by list/answer $l$. Columns must sum zero (for components not represented among $L_{c,i}$) or one (for component represented among $L_{c,i}$). A "other lists" answer, if present, should represent all components not represented by other answers in the same ballot. |
| $E_{c,i}$ | For each $i \in I$ and $c \in C_i$, number of electors in $c$ at the date $t_i$ of the election or poll $i$. Note that this is the number of electors also for polls, not the number of responders. |
| $y_{l, c, i}$ | For each election $i \in I^{election}$, $c \in C_i$ and $l \in L_{c,i}$, the number of valid votes for list $l$ in cell $c$. For elections that allow for candidate-only votes, those should be already allocated to lists following the legal procedure. |
| $r_{l, i}$ | For each poll $i \in I^{poll}$ and $l \in L_{c,i}$, the observed share for answer $l$. |

### Constraints

From $M_{c,i}$ we can derive:
- $A_{c,i}$: for each $i \in I$ and $c \in C_i$, the subset of $P$ represented among $L_{c,i}$;
- $G_{l,c,i}$: for each $i \in I$, $c \in C_i$ and $l \in L_{c,i}$, the set of political components member of $l$.

The member sets
$G_{l,c,i}$ must form a partition:

$$
G_{l,c,i}\ne\varnothing,\qquad
\bigcup_{l\in L_{c,i}}G_{l,c,i}=A_{c,i},\qquad
G_{l,c,i}\cap G_{m,c,i}=\varnothing\quad(l\ne m).
$$

A component belongs to zero or one list on each local ballot.

For any poll $i \in I^{poll}$,
- $L_{c,i} = L^{poll}_{i}$ must be equal for all $c \in C_i$
- $M_{c,i} = M^{poll}_i$ must be equal for all $c \in C_i$

### Reference values

Optional, per-list scenario-provided reference shares should be treated as a poll done at the reference date.

Reference shares sum must be lower than or equal to 1. If the sum is lower than 1, 
the remaining fraction should be assigned to an implicit "other" answer,
representing all the components not yet represented by lists with a reference share.

## Parameters

| Symbol | Definition |
| --- | --- |
| $\eta_{j,t}$ | For each $j\in\{0\}\cup P$ and $t \in T$, latent national log support for component $j$ or for outcome $0$ (abstention plus blank/invalid voting). |
| $\delta_{j,c,t}$ | For each $j \in P$, $c \in C$ and $t \in T$, latent local log shift in support for component $j$ in cell $c$. |


## Model

For $j\in\{0\}\cup P$

$$
s_{j,c,t}=\eta_{j,t}+\delta_{j,c,t}.
$$

### Elections

Let
- $\pi_{j,c,i}$ be the component $j$ probability in cell $c$ and election $i$;
- $p_{l,c,i}$ be the list $l$ probability in cell $c$ and election $i$.

For an election at $t_i$, put

$$
Z_{c,i}=\exp(s_{0,c,t_i})
+\sum_{h\in A_{c,i}}\exp(s_{h,c,t_i}),
$$

$$
\pi_{j,c,i}=
\begin{cases}
\exp(s_{j,c,t_i})/Z_{c,i}, & j\in\{0\}\cup A_{c,i},\\
0, & j\in P\setminus A_{c,i}.
\end{cases}
$$

Aggregate into the actual ballot lists:

$$
p_{l,c,i}=\sum_{j\in G_{l,c,i}}\pi_{j,c,i},
\qquad p_{0,c,i}=\pi_{0,c,i},
\qquad p_{0,c,i}+\sum_{l\in L_{c,i}}p_{l,c,i}=1.
$$

Let 
- $V_{c,i}$ valid attributed votes;
- $y_{0,c,i}$ the abstained electors plus blank/invalid ballot counts.

Then:

$$
V_{c,i}=\sum_{l\in L_{c,i}}y_{l,c,i},
\qquad y_{0,c,i}=E_{c,i}-V_{c,i},
$$

$$
\left(y_{0,c,i},(y_{l,c,i})_{l\in L_{c,i}}\right)
\mid E_{c,i},\boldsymbol p_{c,i}
\sim \operatorname{Multinomial}
\left(E_{c,i},\left(p_{0,c,i},(p_{l,c,i})_{l\in L_{c,i}}\right)\right).
$$

### Polls

Let
- $\pi_{j,c,i}$ be the component $j$ probability in cell $c$ and poll $i$;
- $p_{l,c,i}$ be the answer $l$ probability in cell $c$ and poll $i$.

Use $\pi$ for component probabilities and $p$ for answer probabilities. For a poll at $t_i$, for each $c \in C$, put

$$
Z_{c,i}=\exp(s_{0,c,t_i})
+\sum_{h\in A_{c,i}}\exp(s_{h,c,t_i}),
$$

$$
\pi_{j,c,i}=
\begin{cases}
\exp(s_{j,c,t_i})/Z_{c,i}, & j\in\{0\}\cup A_{c,i},\\
0, & j\in P\setminus A_{c,i}.
\end{cases}
$$

Aggregate into the actual ballot lists:

$$
p_{l,c,i}=\sum_{j\in G_{l,c,i}}\pi_{j,c,i},
\qquad p_{0,c,i}=\pi_{0,c,i},
\qquad p_{0,c,i}+\sum_{l\in L_{c,i}}p_{l,c,i}=1.
$$

And then over all the poll surveyed area, for each $l \in L_{i}$:

$$
p^{poll}_{l,i}=\frac{\sum_{c\in C}E_{c,i}p_{l,c,i}}{\sum_{c\in C}E_{c,i}(1-p_{0,c,i})}
$$

The observed response shares vector $\bm{r}_i$ is then:

$$
\bm{r}_i \sim \text{Dirichlet}(k \bm{p}^{poll}_{i})
$$

where $k$ is a concentration factor (representing poll uncertainty) with an appropriate proper prior.

### Drift

For each interval $\Delta = t_2 - t_1$ between any two consecutive polls and/or elections, from reference date $t_0$ backwards:

$$
\eta_{j,t_{1}} \sim \mathcal{N}(\eta_{j,t_2},\sigma_\eta \sqrt{\Delta})
$$
$$
\delta_{j,c,t} \sim \mathcal{N}(\eta_{j,t_2},\sigma_\delta \sqrt{\Delta})
$$

where $\sigma_\eta$ and $\sigma_\delta$ are parameters governing the drift speed,
with proper priors.

The same equations could be used to estimate $\eta_{j,t}$ and $\delta_{j,c,t}$ for future elections.

## Priors and fitting

Adequate, informative proper priors should be put on $k$, $\eta_{j,t}$, $\delta_{j,c,t}$, $\sigma_\eta$ and $\sigma_\delta$ to ensure convergence in case of sparse data.

If fitting is done using a Monte Carlo method, initial values should be chosen 
adequately in order to speed up convergence.
