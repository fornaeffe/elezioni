## Data


| Symbol | Definition and domain |
| --- | --- |
| $P$ | Stable political components required by the selected history and scenario; $K=\lvert P\rvert\ge1$ and $D=K+1$. |
| $0$ | Combined abstention plus blank/invalid voting, measured among electors. |
| $I$ | Historical Camera elections, polls and reference pseudo-polls admitted by the information cutoff. |
| $t_i$ | Observation date of source $i$ |
| $t_{next}$ | Date of the election to be simulated |
| $U_i$ | Geographical units for which the results of source $i$ are reported (commonly, municipalities at the time of election for elections; a single geographical scope for polls) |
| $U_{next}$ | Geographical units for which the votes are to be estimated (e.g. colleges of the election to be simulated) |
| $C$ | Physical cells required to describe, by composition, every $U_i$ and $U_{next}$, i.e. the coarsest common refinement or the overlay of every $U_i$ and $U_{next}$ |
| $u_i(c)$ | Geographical unit from $U_i$ that contains physical cell $c \in C$ |
| $u_{next}(c)$ | Geographical unit from $U_{next}$ that contains physical cell $c \in C$ |
| $E_{c,i}$ | Nonnegative integer electorate of cell $c$ at $t_i$; this is not a poll sample size. Each source has positive total electorate. |
| $L_{u}$ | For each source $i$ and unit $u \in U_i$, political lists or question answers offered in unit $u$. |
| $M_{c,i}$ | Binary list/answer by component membership matrix. Each column sums to zero or one; every political answer represents a nonempty component set. |
| $A_{c,i}$, $G_{l,c,i}$ | Offered components and the members of political list/answer $l$, derived from $M_{c,i}$. |
| $\bm{y}_{u}$ | For each source $i$ and unit $u \in U_i$, observed election counts in unit $u$ from source $i$; nonnegative integer vector. |
| $\boldsymbol r_i$ | Complete, normalized reported composition, with entries in $[0,1]$. Retain the original published values and normalization provenance. |
| $n_i$, $\boldsymbol z_i$ | Positive integer respondent base and observed/reconstructed answer counts, with $\sum_l z_{l,i}=n_i$. References have $n_i=1000$. |
| $d_i$ | One for Senato elections; zero for Camera elections or polls. |

For political lists, the nonempty sets $G_{l,c,i}$ partition $A_{c,i}$:

$$
\bigcup_{l\in L_{c,i}}G_{l,c,i}=A_{c,i},
\qquad G_{l,c,i}\cap G_{m,c,i}=\varnothing\quad(l\ne m).
$$

Define separately $G_{0,c,i}=\{0\}$. Outcome $0$ is always available.
For a poll or reference question, $L_{c,i}$ and $M_{c,i}$ are constant over
$C_i$. A declared Other answer represents the exact offered complement.
An absent component is not an observed zero.

Use a nonoverlapping geographic partition for each source. If a catalogue
contains both Camera and Senato cells, select the relevant partition or a common
refinement; never sum both representations of the same electorate for a poll.


### Reference values

Optional, per-list scenario-provided reference shares should be treated as a poll done at the provided reference date.

Reference shares sum must be lower than or equal to 1. If the sum is lower than 1, 
the remaining fraction should be assigned to an implicit "other" answer,
representing all the components not yet represented by lists with a reference share.

## Model


For each college $u \in U_{next}$ and each component $j \in \{0\} \cup P$

$$
s_{j,u} = \eta_{j} + \delta_{j,u}
$$

For each cell $c \in C$, each source $i \in I$ and each component $j \in \{0\} \cup A_{c,i}$

$$
\pi_{j,c,i} = \frac{e^{s_{j,u_{next}(c)}}}{\sum_{h \in \{0\} \cup A_{c,i}} e^{s_{h,u_{next}(c)}}}
$$

For each source $i$, $u \in U_i$, $l \in L_{u}$

$$
p_{l,u} = \frac{\sum_{c \in u} \sum_{j \in G_{l,c,i}} E_{c,i} \pi_{j,c,i}}{\sum_{c \in u} E_{c,i}}
$$

Let $\Delta = t_{next} - t_{i}$.

For Camera elections:

$$
\bm{y}_u \sim \text{MultinomialDirichlet}\left(\sum_{c \in u } E_{c,i}, \frac{\bm{p_u}}{e^{\lambda_{Camera} \Delta} - 1} \right)
$$

For polls, let $u$ the poll's geographic scope:

$$
\boldsymbol z_i \sim \text{MultinomialDirichlet}\left(n_i, \frac{\bm{p_u}}{e^{\lambda_{polls} \Delta} - 1} \right)
$$
