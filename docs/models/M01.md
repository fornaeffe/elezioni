# M01 2.0.0 — fixed correspondences and list shocks

Status: implemented; alternative to [M02](M02.md). This version restores the
implementation immediately before `4ee5a91` (parent `1c19d54`): historical
component compositions project onto future **lists**, and generation applies
list-level shocks. Geography, scenario editing, candidature/preferences and
legal scrutiny remain shared. The [1.0.0 definition](archive/M01-1.0.0.md) records
the superseded component-pooling and pre-filing law.

## Identity and semantic versioning

Canonical identity: **M01@2.0.0**. Scenarios store
`generation: { model: "M01", modelVersion: "2.0.0", ... }`; the registry is
[`model-registry.ts`](../../web/src/lib/politics/reform-2026/vote-share/model-registry.ts).
M02 has an independent version sequence. The law and accepted reference meanings
change from 1.0.0, requiring MAJOR. Old versions/selector aliases are rejected;
there is no automatic statistical conversion of saved scenarios or results.
Historical receipts keep their original identifiers and measured scope.

[Semantic Versioning](https://semver.org/) is appropriate with an explicit public
contract: accepted inputs, denominators, probability law and output meanings.
Apply these rules independently to M01 and M02:

| Increment | Model-contract meaning |
| --- | --- |
| MAJOR | Change the law, assumptions, existing-input behavior or input/output meanings; changing a model-level default law also counts |
| MINOR | Add optional capabilities whose absence preserves every existing configuration's law and meanings |
| PATCH | Clarify the specification or correct an implementation to the same specified law without changing the contract |

A correction that changes the specified law needs MAJOR even if called a bug fix.
Released specifications are immutable; record a new version when their normative
content changes. Version 2.0.0 restores an earlier law; it does not establish predictive calibration.
Exact replay additionally requires source/scenario IDs, fitted-state IDs, numerical
policy versions, RNG version, seed and implementation hash. A data refresh, code
refactor or file-schema revision is not automatically a new statistical model.
The browser currently accepts exact supported model versions, not SemVer ranges.

## Notation and pipeline

$c$ is a municipality, $r(c)$ its region, $h\in\{C,S\}$ Camera/Senato,
$g$ an original historical group, $j$ a component and $l$ a future list.
$E_{ch}$ is the conditional target electorate. Non-valid support combines
abstention, blank/invalid ballots and other non-list residual outcomes.
Political references use valid-vote denominators; non-valid references use electors.
Poll voting-intention percentages do not measure electoral turnout/nonresponse.

The pipeline is: eligible original paired election → historical counts rescaled
to target electorates → compositions/correspondences → municipal future-list
shares with historical turnout → latest named poll refresh → manual references
→ national/regional/municipal list shocks → joint integer apportionment → college
reconstruction → shared legal assembly. Municipal filing availability is the
union of the physical colleges touching that municipality.

## 1. Historical baseline and source compositions

Use the latest cutoff-eligible same-date Camera/Senato pair with common age-18+
electorates. Both event and availability dates must be eligible; no pair means
preparation fails. Keep original list counts distinct. A uniquely matched valid
municipality uses its own original counts. Missing/invalid municipality history
uses eligible regional original counts, labelled in `missingHistory`. Rescale
all political counts plus non-valid support jointly to $E_{ch}$ with deterministic
integer apportionment. No held-out vote outcome enters this preparation.

For declared nonnegative source weights $w_{gj}$ on original membership $S_g$,

$$
W_{gj}=\frac{w_{gj}}{\sum_{k\in S_g}w_{gk}},\qquad
C_{glh}=\sum_{j\in S_g}W_{gj}A_{lhj}.
$$

$A$ is binary future list membership, not future-list composition weights.
A missing composition uses equal original-member weights; the default authoring
pipeline records explicit equal-weight assumptions for joint groups. Explicit
zero weights remain structural members. Weights must be finite, nonnegative and
have positive total; missing weight entries in a supplied row are zero. An
explicit provenance-bearing proxy is allowed only for an opaque historical group,
never an invented poll identity. Canonical aliases are resolved before mapping.
Overlapping future carriers on the same physical ballot fail.

This representation does not infer original component counts. List regrouping
changes stochastic coordinates. A component offered on different territorial
tickets can map to several labels; those labels have separate shock coordinates.

## 2. Municipal projection, turnout and fallback

Let $x_{cgh}$ be rescaled original counts. For lists available anywhere in $c$,

$$
R_{clh}=\mathbf1_{l\in F_{ch}}\sum_g x_{cgh}C_{glh},\qquad
q_{clh}=\frac{R_{clh}}{\sum_kR_{ckh}},\qquad
a_{ch}=1-\frac{\sum_gx_{cgh}}{E_{ch}}.
$$

Retain the **original** valid fraction $1-a_{ch}$. If mapped mass is positive,
incomplete mapping redistributes the original valid total over retained
destinations. With no mapped support but positive original valid mass, use raw
mapped regional donor counts restricted to filed lists; without donor mass use
equal weight per filed list. Snapshot donors before fallback installation to
avoid order dependence. Positive valid mass without any filed list is an error.
Warnings expose the regional/equal-list proxy.

These are restored assumptions and discontinuities: there is no component-wise
conditional-frequency completion and no half-vote regularization of observed
political zeros. Zero support remains zero unless an explicit poll/reference
intervention seeds it.

## 3. Latest-publication poll refresh

Use eligible enabled Camera observations, ordered by latest availability,
fieldwork end and stable ID. Project named groups independently through each
chamber's future memberships. For poll group share $s_g$,

$$
u_{lh}=\sum_gs_g\frac{C_{glh}}{\sum_k C_{gkh}}.
$$

An unmapped group supplies no named point. Repeated labels/components in a
question and opaque poll proxies fail. Normalizing mapped destinations can
transfer a whole group to a surviving label or divide a national point between
territorial ticket labels without geographic weighting. These are assumptions,
not observed voter substitutions.

A list without a historical correspondence in its chamber uses its newest
eligible named point as the new-list exception. A partly new joint list is not
separately new. Established lists refresh from the latest publication only.
Unreported lists retain a proportional historical remainder. If mixed-wave named
points sum to at least one, normalize them while retaining historical unreported
mass and record the adjustment. The final ordinary-list vector sums to one.

Reconcile polls over municipalities touching ordinary colleges; exclude special
ballots. Preserve municipal turnout and filing zeros. Missing support can use a
labelled donor profile or near-flat filed seed. One common reference date dates
the refresh; original source dates remain in the audit. This is not the separate
14-day-decay/one-wave-per-house polling estimator.

For named point $u_l$ and effective sample $n_l$, measurement SD is

$$
s_l=\sqrt{\left[\frac{\sqrt{u_l(1-u_l)/n_l}}
{\max(0.01,u_l(1-u_l))}\right]^2+0.08^2}.
$$

Baseline-derived remainder rows have zero extra SD. A measurement draw is shared
nationally and across chambers per **future list ID**; deterministic group splits
do not share one original-group draw across distinct destination labels.

## 4. Manual references and scopes

Manual list references override polls. Component references affect M01 only when
they identify a singleton future list; a subset of a joint list has no effect.
Scenario reference SDs are ignored. Non-valid references remain separate.
Common political references use historical chamber contrast:

$$
\delta=\tfrac12g\operatorname{clip}_{[-1,1]}
[\operatorname{logit}b_S-\operatorname{logit}b_C],\qquad
R_C=\operatorname{logistic}(\operatorname{logit}R-\delta/2),\quad
R_S=\operatorname{logistic}(\operatorname{logit}R+\delta/2).
$$

Endpoints are exact; explicit chamber references override common values. Resolve
national → region → province → municipality. Normalize overfull vectors, or fully
specified vectors not summing to one, with a warning; an all-zero fully specified
vector fails. Multiplicative reconciliation fixes supplied valid-weighted list
margins, retaining free local proportions, turnout and filing zeros. Check
individual filed capacity; allow at most 1,000 iterations and require margin
residual below $10^{-9}$. Incompatible support/nonconvergence fails. Individual
capacity checks do not prove joint feasibility.

Non-valid references shift local non-valid log odds to the elector-weighted
aggregate, preserving exact endpoints. Specific references can change broader
totals. There is no unrestricted reference-date component field.

Manual references date national and territorial shocks at the scenario projection
date and remove that row's poll measurement error. Poll refresh dates national
shocks at its common date, retaining historical territorial ages. Unreferenced
support retains historical ages.

## 5. List movement and integer counts

For chamber-profile shared variance $v$, residual correlation $r$ and independent
standard Normals $Z_*,Z_C,Z_S$ per list/geographic coordinate,

$$
\epsilon_C=\sqrt v Z_*+\sqrt{1-v}Z_C,\qquad
\epsilon_S=\sqrt v Z_*+\sqrt{1-v}(rZ_C+\sqrt{1-r^2}Z_S).
$$

Marginal variances are one; cross-chamber correlation is $v+(1-v)r$. Use the
configured national/regional/municipal SDs per square-root day,
$\sigma_N,\sigma_R,\sigma_L$. For elapsed ages $D_N,D_T\ge0$ in days,

$$
B_{clh}=\sqrt{D_N}\sigma_N\epsilon_{N,lh}
+\sqrt{D_T}(\sigma_R\epsilon_{R,r(c),lh}
+\sigma_L\epsilon_{L,c,lh})+s_lZ_l.
$$

The measurement term applies only to poll-derived rows. Non-valid support has
its own national/regional/local shocks and age, without a poll measurement term.
Distinct list IDs have independent innovations, including shared ancestry;
matching IDs share national/regional fields and chamber coupling. M02 uncertainty
multipliers do not alter M01.

For reference elector shares $p_{clh}=(1-a_{ch})q_{clh}$,

$$
w_{clh}=\operatorname{logistic}(\operatorname{logit}p_{clh}+B_{clh}),\qquad
w_{c0h}=\operatorname{logistic}(\operatorname{logit}a_{ch}+B_{c0h}),\qquad
\pi_{clh}=\frac{w_{clh}}{w_{c0h}+\sum_kw_{ckh}}.
$$

Zero political support stays zero. Non-valid 0/1 endpoints bypass the logit;
other logit arguments are clipped to $[10^{-9},1-10^{-9}]$ by the restored
helper. A political unit endpoint therefore uses that arithmetic convention.
Allocate all $E_{ch}$ electors jointly from
weights rounded at $10^{12}$ resolution using seeded integer apportionment.
This is **not** a multinomial draw. Electors are conserved, including non-valid
counts; logit shocks and normalization need not preserve predictive means.

## 6. College reconstruction, provenance and limits

Generate municipal counts, then apportion electors and list votes to physical
colleges using census population weights. The restored greedy allocator processes
lists in order, respecting filing and remaining electorate capacity. It can
reject feasible split allocations or expose targets admitted by the municipal
filing union. These are retained rollback limitations; direct physical-cell
counting and a transportation solver are not part of this law. Derive the Camera
TAA proportional view once from the physical ballots.

Use shared candidature/preference generation and legal scrutiny. Record public
model/version, source/scenario/input IDs, seed/RNG/implementation identities,
baseline pair, missing-history/poll audits, resolved references and proxy/failure
warnings. Functional success is separate from predictive calibration. Previous
legacy comparisons retain their recorded procedure and are not a new 2.0.0
acceptance campaign.
